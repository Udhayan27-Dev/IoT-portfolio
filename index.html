IoT Engineering Portfolio

ESP32-C3 (RISC-V) · Bare-Metal Rust (no_std) · Embassy · Adafruit IO · MQTT · Voice Automation · Firebase

This portfolio documents my end-to-end IoT engineering projects built on the ESP32-C3 RISC-V microcontroller. Unlike traditional Arduino C++ sketches, these systems leverage bare-metal Embedded Rust (no_std) with the asynchronous Embassy runtime, providing compile-time memory safety, zero-cost abstractions, deterministic concurrency, and maximum resource efficiency.

The projects demonstrate a progressive evolution from a local embedded HTTP web server to cloud-connected MQTT brokers, voice assistant integration, and enterprise Firebase telemetry and automation dashboards.

Task 1 ESP32-C3 Web Server & HTML LED Control Bare-metal async Rust HTTP server hosting an interactive web UI on port 80 to toggle an LED. Task 2 Adafruit IO Dashboard & Async MQTT Relay Zero-allocation async MQTT 3.1.1 protocol client in Rust switching an AC mains bulb via an active-LOW relay. Task 3 Voice Assistant & Cloud Automation Google Assistant voice commands routed through IFTTT webhooks to Adafruit IO MQTT for hands-free lighting. Task 4 Firebase IoT Monitoring Dashboard DHT11 temperature/humidity and ambient LDR sensing with secure Firebase Auth and real-time cloud control. Task 5 Firebase Logging, Automation & CSV Export Automated lighting control based on ambient LDR thresholds, historical RTDB logging, interactive charts, and CSV data export.

Architecture Highlights: Why Embedded Rust?

Memory Safety Without Garbage Collection: Rust guarantees no null pointer dereferences, data races, or buffer overflows at compile time. In resource-constrained embedded systems with only 400 KB of RAM, memory bugs that cause silent stack corruption in C/C++ are caught before flashing.

Cooperative Asynchronous Concurrency with Embassy: Traditional RTOS systems (like FreeRTOS) allocate individual stack memories for every thread (typically 4 KB per task). Embassy uses Rust's native async/await statemachines, running multiple concurrent tasks (Wi-Fi controller, network runner, MQTT client, TCP listener) on a single runtime stack with virtually zero RAM overhead.
